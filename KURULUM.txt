ÇARK FUTBOL – BİRLEŞİK MAÇ MOTORU, CANLI ANLATIM VE ADMIN GİRİŞ DÜZELTMESİ

GitHub Pages deposunda şu üç dosyayı aynı konumda değiştirin:
- index.html
- app.js
- styles.css

Bu sürümde admin giriş düğmesinin tıklama olayı doğrudan app.js içinden bağlanır; HTML içi bağımsız handler kaldırılmıştır.

Şu dosyalara dokunmayın:
- firebase-config.js
- firestore.rules
- players.json

Yükledikten sonra GitHub Pages'in dağıtımının bitmesini bekleyin, siteyi Ctrl+F5 ile yenileyin ve “Admin girişi” düğmesini tekrar deneyin. Bu paket sözdizimi kontrolünden geçirilmiştir; gerçek Firebase ortamında canlı uçtan uca test yapılmamıştır.
